## 1. 总体流程

提取四边 → 恢复边界解析表达 → 检查相对边的几何关系 → 构造解析母面 → 恢复参数范围 → 验证。

识别不依赖 SurfaceForm 等来源标签，也不要求固定节点、控制点或权重排列。

## 3. 接口和结果

在模块命名空间 bspline2analytic 内提供 AnalyzeBoundaries 和 Recognize 两个入口，接收 const sggk::BSplineSurface& 及 RecognitionOptions。

RecognitionOptions 包含距离容差和验证工作量限制。RecognitionResult 包含状态、sggk::SurfaceType、解析曲面对象、四边信息、解析参数范围、方向对应和验证报告。

状态区分成功、输入无效、几何退化、数值条件不足、边界关系不一致、结果有歧义和验证失败。验证报告区分采样残差与已经获得的全域误差界。

## 4. 边界提取

四条边界按 Umin、Umax、Vmin、Vmax 保存：

- Umin(v) = S(umin, v)，Umax(v) = S(umax, v)。
- Vmin(u) = S(u, vmin)，Vmax(u) = S(u, vmax)。

SGK 的 CalcVCurve(u) 固定 u、沿 v 变化；CalcUCurve(v) 固定 v、沿 u 变化。

优先调用内核等参线接口。直接使用控制网最外行或列，仅适用于满足相应端点夹持条件的情况。

## 5. 直线与圆弧识别

先检查区间、权重、分母有效性及退化情况，再进行局部平移和尺度归一化。

直线候选利用局部控制点共线性恢复，随后验证几何偏差；圆弧求解使用秩判断。共线性使用数值分辨率而非用户距离容差，避免把误差容限内的短圆弧直接当作直线。极端尺度下仍可能因分辨率不足而无法恢复。

圆弧先检查共面性，再通过 ToBezierCurves 将曲线分成有理 Bézier 段。在局部平面内，设 x = X/W、y = Y/W。圆方程对应恒等式：

    X² + Y² + a XW + b YW + c W² = 0

将乘积展开到 Bernstein 基，利用所有段的系数建立关于 a、b、c 的线性方程组。采用带秩判断的 QR 等数值方法，不直接使用正规方程。

恢复：

    xc = -a/2
    yc = -b/2
    r² = (a² + b²)/4 - c

所有分段必须对应同一个圆。验证时考虑权重分母界，并把残差换算为几何量，不能直接将平方量与距离容差比较。

输出直线的基点、单位方向和区间；输出圆弧的圆心、半径、圆面法向、局部基、起始角和有向扫角。解析角度通常不是原 NURBS 参数的线性函数。

## 6. 解析母面恢复

### 平面

四边均为直线时检查共面、相对边平行及非退化性。若同时确认 SGK 标准参数域等参性，再检查两组边界方向与其局部参数坐标轴的对应。

### 圆柱

一组直线和一组圆弧时，检查圆面平行、圆心连线垂直于圆面、两圆共轴等半径、直线平行于轴线且轴距与半径一致。

### 圆锥

同锥瓣普通面片中，设圆心 O0、O1，半径 r0、r1，h = |O1-O0|，轴向 a = (O1-O0)/h，k = (r1-r0)/h。

    锥顶 A = O0 - (r0/k) a
    半锥角 alpha = atan(|k|)

随后检查两条母线延长线是否经过锥顶，以及夹角是否一致。浅锥结合母线关系判断。跨锥顶输入需要锥瓣与带符号径向分支，不直接套用上述公式。

### 球面

依次尝试两组相对圆弧。某组同心等半径时构造球心 C、球半径 Rs 候选。

其余边界圆（圆心 O、单位法向 n、半径 r）应满足：

    O-C 平行于 n
    |O-C|² + r² = Rs²

并检查纬线共轴、经线平面包含该轴等关系。两条经线可以位于同一个支撑圆，不要求它们的法向必然不平行。

### 圆环面

尝试两种边界族分工：一组作为平行圆，另一组作为管截面圆。轴向取自平行圆法向，不仅依赖两圆心连线。

普通圆环中，设轴线 P+t a，管截面圆心 M、半径 r：

    C = P + ((M-P)·a) a
    R = |M-C|

用另一管截面圆和全部平行圆验证相同的中心、轴线、主半径及管半径。保留 SGK Apple/Lemon 的分支信息，对带符号主半径及奇异参数范围使用专门规则。

球面检查失败后，必须实际构造并验证圆环候选，不能直接归为圆环。

### 必须覆盖的反例

主半径 3、管半径 1 的圆环，其 v=0 和 v=pi 两条平行圆都以原点为圆心，半径为 4 和 2。因此“存在一组同心圆”不足以判为球面。

## 7. 参数范围与验证

利用边界点的解析反参数化恢复范围，记录 U/V 交换、方向反转和周期展开。圆弧范围需结合遍历方向及中间点，不能只凭端点区分长短弧或整周。

先做边界及各节点区间内点的快速残差检查。全域误差估计使用 Bézier 分块、Bernstein 系数界和必要细分；工作量上限内无法建立界时，报告未完成验证。当前实现使用浮点保护项，尚未使用定向舍入的严格区间算术。报告中的全域界针对解析母面，不声称已证明裁剪面片之间的双向 Hausdorff 界；范围与方向恢复也仍使用采样追踪。

四边相同不能作为内部母面一致性的唯一证据。

## 8. 构建接入

已建立 BSpline2Analytic 静态库、BSpline2AnalyticSample 示例和 BSpline2AnalyticTests 测试目标，采用 C++17。

现有 samples/src/CMakeLists.txt 已自动添加子目录。模块源文件使用显式列表，避免将多个 main 编入同一目标。

当前 SDK 的实际位置为 SGK 根目录下的 SGGK。现有 samples 生成脚本默认使用 samples/SGGKLib 和 _ar 后缀，与当前 SDK 布局不一致。模块的独立构建入口显式设置 SGGK_SDK_DIR，直接链接 SGGK_ 前缀且无 _ar 后缀的五个 SDK 库，使用独立构建目录，并匹配各配置的运行库。若由现有 samples 顶层工程调用，还需在顶层传入 SDK_PREFIX=SGGK_、SDK_SUFFIX 为空和正确 SDK 路径。当前验证采用独立入口，不修改厂商顶层工程。

SDK 和许可证在本地配置，不进入仓库。
