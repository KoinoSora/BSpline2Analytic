# 连续边界误差曲线优化与定向测试

日期：2026-10-15。基线：`d5bb72e`。Windows x64、MSVC Release、SGK 1.7.11，区间相关编译单元使用 `/fp:strict`。

本轮只修改并测试 `ValidateGeneralRationalBoundaries`。旧 `ValidateGeneralHybrid`、旧投影验证器及其间接转换入口均未运行；比较双方都是当前 NURBS 参数域直线边界验证器的不同代码版本。没有运行全量数据集。

## 实现范围

借鉴“曲线转化”会话中 `NURBS2BSpline.cpp` 的齐次误差系数联合构造方法，在 `src/GeneralBoundaryError.cpp` 增加一维内核。

对同一局部参数 τ∈[0,1] 下的源边 S=A/w 和输出边 T=B/v，误差为 E=T−S=G/H，其中 G=Bw−Av，H=wv。若源、目标分别为 p、q 次齐次曲线，则以

`α(i,j)=C(p,i) C(q,j) / C(p+q,i+j)`

在一次控制系数对遍历中累加 G 的三个分量和 H，避免分别构造两个向量乘积后相减。组合系数按次数缓存在本次认证上下文中。常权曲线保留已有乘法、升阶路径，避免为联合计算人为提高权重次数。所有运算采用原有向外舍入区间；不删除“小系数”，不降低输入次数，不改变容差。

认证顺序改为：

1. 构造误差曲线，先求位置上界 d；箱界不够紧时继续用控制系数界。
2. 位置未认证的节点直接进入既有对应关系细分，不计算该节点的切向。
3. 位置通过后，先用误差导数给出切向的充分判据。由 `E′=G′/H−E H′/H`，令 h₀ 为 H 的正下界、g₁ 为 ‖G′‖ 的上界、h₁ 为 |H′| 的上界，则 `M=(g₁+d h₁)/h₀` 是 ‖E′‖ 的上界。
4. 源导数分子 `Dₛ=A′w−Aw′` 的系数箱到零的距离，除以源权重最大值的平方，给出源速度下界 m。若 M<m，则两切向同向，且 `tan(θ)≤M/(m−M)`；严格小于角度容差的正切下界即可通过。
5. 快速判据无法通过时，复用已算好的 Dₛ，再构造目标导数及完整叉积／点积界。速度下界为零、速度差过大均为“无法快速判定”，不直接判失败。

上述导数均针对配对后的同一个局部 τ，包含当前分段仿射对应的速度尺度。对应关系改变时仍重建误差曲线。本轮没有实施跨重新映射的系数复用，也没有改变细分策略。

内部仍为增强 Greville 采样验证；四边位置、切向仍为连续区间认证。输出仍为母面及四条实际 SDK NURBS 曲线，输出到母面的舍入认证保留。正式统一转换入口未在本轮切换。

## 验证与计时口径

最终 `GeneralRationalBoundaryUnit` 通过 **9920 项断言**，CTest 约 0.19 s。新增检查包括不同次数、常权／变权组合的误差值独立求值、同向小扰动、切向超差、纯平移、反向、零源速度、齐次尺度变换，以及完整验证器中“同向变速通过后备认证”和“切向超差经后备仍拒绝”。SDK 初始化输出两行日志文件打开失败提示，测试退出码为 0，断言全部通过。

性能选择 7 个历史输入和 5 个双五次、200 控制点压力输入，共 **12 例**。每例双方各 5 次、按轮交替先后顺序，每次启动独立进程、重新创建验证上下文；最终共 **120 行**。历史输入走真实分类候选，压力输入提供已知母面和固定参数图。读取、输入来源证书、进程启动和输出 SDK 审计在算法计时外；分类、全部候选验证及调度计入历史案例的 `pipeline_ms`。压力输入不包含分类。这个总耗时不是正式统一转换器的完整耗时。

首轮同批测量也保留。之后只补充后备分支的完整验证器单测，重新构建最终测试程序并测量最终批次；生产实现未改变。两批共 240 行，均没有异常、超时、输出审计失败或接受结果变化。未固定 CPU 亲和性，机器非独占，不能据此推断生产 P95/P99。

## 最终测量结果

以下均为 5 次中位数，单位 ms。通过的 10 个案例均为 5/5；254 和 500 均为 0/5，与基线一致。

| 案例 | 输入次数 / 控制点数 | 边界认证：前→后 | 总耗时：前→后 |
| --- | --- | ---: | ---: |
| 000 平面 | 3×3 / 50 | 0.596 → 0.309 | 2.157 → 1.882 |
| 100 圆柱 | 6×6 / 63 | 5.568 → 1.699 | 7.968 → 4.114 |
| 200 球面 | 6×6 / 63 | 4.508 → 1.204 | 7.445 → 4.391 |
| 218 球面退化边 | 6×6 / 63 | 5.730 → 1.510 | 8.609 → 4.295 |
| 318 圆锥退化边 | 6×6 / 63 | 1.358 → 0.507 | 3.670 → 2.791 |
| 254 球面，未恢复当前合同参数图 | 6×6 / 120 | 未进入 | 3.203 → 3.184 |
| 500 无解负例 | 3×3 / 100 | 未进入 | 2.063 → 2.106 |
| 压力平面 | 5×5 / 200 | 0.766 → 0.373 | 4.469 → 3.923 |
| 压力圆柱 | 5×5 / 200 | 3.475 → 1.162 | 7.454 → 5.024 |
| 压力球面 | 5×5 / 200 | 4.682 → 1.379 | 9.100 → 5.567 |
| 压力圆锥 | 5×5 / 200 | 3.503 → 1.175 | 7.486 → 5.097 |
| 压力圆环 | 5×5 / 200 | 4.479 → 1.350 | 8.721 → 5.588 |

圆柱 100、球面 200、218 的边界认证分别加速约 **3.28、3.75、3.80 倍**。五类压力样本的边界认证约加速 **2.06～3.40 倍**。优化后最终批次 60/60 次总耗时低于 10 ms，其中 50 次通过、10 次保留未认证结果；最大值 **6.8672 ms**。首轮最大值 6.4343 ms。失败返回不能计作成功转换加速。

小案例仍受测量波动影响：首轮平面 000 总耗时中位数为 1.689→2.088 ms，最终批次为 2.157→1.882 ms；两个批次的边界认证耗时均下降。无解负例没有进入新边界内核，总耗时也不承诺改善。

最终批次的 1500 次快速切向检查全部通过，避免对应的目标导数及点积／叉积构造；270 个位置未通过的节点跳过切向。所选性能样本没有触发完整切向后备，但单测同时覆盖其通过和拒绝分支。节点数、映射细分次数与基线一致：圆柱 100 为 52/22，球面 200 为 32/12，218 为 42/17；五类压力样本均为 40/0。这表明主要收益来自每个节点减少计算，而非放宽精度或少做必要细分。

通过结果的最大连续位置界为 `8.8089220335e-6`，最大切向上界为 `0.065307302°`，均满足原容差 `1e-5` 和 `0.1°`。最大输出母面界为 `4.2271332202e-13`；独立 SDK 边界采样审计最大距离为 `2.1475025411e-10`。快速切向界可能比完整叉积界保守，报告角度上界变大不代表输出几何误差变大。独立采样审计用于交叉检查，连续结论来自区间认证。

历史 `general-*.b2a` 确实仍有双六次输入；本轮保留其原始次数以单独评估算法优化。双五次压力样本也明显受益，说明耗时并非仅由超过五次造成。优化后压力样本准备阶段约 2.28～2.60 ms，高于边界阶段的 0.37～1.38 ms；后续应优先分析源边提取及输出构造，是否继续做直接细分复用应由剩余慢例决定。
