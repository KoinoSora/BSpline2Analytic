### 本批暴露的问题与修复

1. 圆锥角度界丢失共同高度缩放关系。改用正分母 Bernstein 系数比值的凸包界，避免对两个独立坐标区间相除；新增相关性和非正分母回归检查。
2. 球面重拟合的微小圆心差产生了大半径近零的圆环候选，原排序先尝试奇异极限，浪费验证预算。已有合格采样评分球面时将此类圆环后移，候选不删除，最终接受仍依赖完整验收。
3. 圆环管截面角度的区间旋转丢失相关性。用代数消元保留分子的 Bernstein 多项式，分母可能过零时保守回退；参考角改为选择较近边界，避免窄区间上边界一直相对下边界估计。

这些修复没有改动距离/角度容差、验证预算或数据。中间诊断与被停止的测试不计作最终通过结果；以上数据来自修复后完整的五组回归。
