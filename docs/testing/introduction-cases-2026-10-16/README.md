# 作品介绍第六章定向案例证据

日期：2026-10-16。基于 `898a0d9` 的算法源码，新增独立文档取证程序，不修改转换算法。源码、可执行文件、输入与原始结果哈希见 `provenance.json`。

## 案例来源与计时

- `sphere-317`：Dataset500 的 `case-317.b2a`，非有理五次/五次样条，64 个控制顶点，一条源参数边坍缩至球面极点。
- `cone-217`：Dataset500 的 `case-217.b2a`，非有理五次/三次样条，64 个控制顶点，一条源参数边坍缩至圆锥顶点。
- `torus-triangle`：本次补充的独立正例。沿用 V2 `main-400` 的规则圆环母面参数，由当前独立来源生成器重建三角形裁剪面片；角度框架角点按 00、10、01、11 顺序为 `(0.2,0.2)、(1.4,0.2)、(0.2,1.1)、(0.2,1.1)`，转换成目标 NURBS 图后为直线边界；Vmax 整边坍缩。保存为本目录 `torus-triangle.b2a`。有理三次/四次，63 个控制顶点。不是规则圆环母面自身的奇点，也不是既有全量数据中的案例。

三个输入均在计时前通过来源认证。算法只收到输入曲面与默认选项，未接收来源母面或图。调用 `ConvertIsoThenFallback`，默认总预算 50 ms，等参子预算 20 ms；每例三次，每次建立新的算法上下文，无逐例预热。外部 `steady_clock` 从 API 调用前计至 API 返回后，保留第一调用。顺序执行的同一进程中，输出审计和图形导出发生在两次调用之间，均在计时之外。未固定 CPU 亲和性、未独占机器。

构建：Windows x64、MSVC 19.42、Release。先完成构建再测量；测试时另外检查绘图库可用性，无独占性能保证。初始化时出现 SDK 的 `Failed to open log output file` 提示，进程退出 0，9 次算法和输出审计均成功。绘图库随后安装与绘图，未与算法计时重叠。

## 结果

| 案例 | 成功且审计通过 | 整体均值/ms | 整体最大/ms | 三次均 <10ms | 三次均 ≤50ms | 连续边界距离上界/mm |
|---|---:|---:|---:|---|---|---:|
| sphere-317 | 3/3 | 5.433733 | 6.9672 | 是 | 是 | 4.133721757786145e-7 |
| cone-217 | 3/3 | 2.392133 | 2.7237 | 是 | 是 | 5.221223662664777e-7 |
| torus-triangle | 3/3 | 2.313567 | 2.3761 | 是 | 是 | 2.717351028835391e-11 |

所有调用均先进入等参、随后进入一般兜底。三个案例每次都报告一条整边坍缩，微小分段切向豁免数量为零，母面优化迭代数量为零。非坍缩边界切向角度上界分别为 0.0010718745223675472°、0.001360919982125655°、2.5542726363877026e-9°。坍缩边的切向不适用，不将其计为零角度认证。

输出审计复用当前串联测试的独立检查：核对输出类型、共享端点坐标、实际 SDK 边界到母面的距离、源边界到输出曲线的最近点距离以及非退化区间的切向；另作内部母面距离采样。不能将该独立采样审计解释为全域连续证明。

本节只提供三个定向正例的证据，不是新版全量回归；不覆盖优化器效果、相邻面 G1 或全域连续内部误差。既有全量非极端回归仍存在预算失败，本批次不覆盖或替代该历史结果。

## 图片与复现

`*-geometry.csv` 中的 `source` 来自输入曲面 51×51 求值；`target` 用恢复后的母面、参数图及参数角点生成有限面片显示网格，并非输出拓扑面；`output_edge` 来自实际内核输出曲线求值。`collapsed` 为整边坍缩位置。热图使用源采样点到恢复母面的距离，不是边界误差界或全域上界。

图形在同一恢复母面的局部正交坐标系内显示，左右采用相同相机及等比例缩放，不对几何误差进行位移放大。相机依据面片局部法向选择，完整展示三角形区域。每个热图使用自己的颜色范围，跨图比较须读取色标。

图片位于 `../../algorithm/work-introduction/figures/`，同时保存 PNG 和 SVG。绘图只读取结果 CSV，不重新运行算法。`summary.json` 中 `plot_sample_max_mm` 为 51×51 绘图采样最大值，`runs.csv` 中 `audit_position_max` 为独立 13×13 审计采样最大值，两者采样密度不同。
