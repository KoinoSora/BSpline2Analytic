`exclusion` 记录尝试次数、状态、见证数、耗时、距离下界、归一化尺度、左逆残差上界、左逆范数上界、梯度上界和原因。状态包括未尝试、未能证明、已证明排除和局部预算耗尽。只有“已证明排除”可用于拒绝，其他状态继续原流程。若总截止时间耗尽，保留原有超时语义。

## 排除证书及其边界

对世界坐标中的输入曲面，以控制点包围盒中心和平移后尺度的二次幂进行均匀归一化。每个非零结点单元提取为带区间系数的齐次 Bézier 面片，在两方向的 0、1/4、1/2、3/4、1 处计算区间点值。分母必须严格为正；验证覆盖真实存储系数对应的源曲面点值及归一化舍入误差。

任意位置和方向的平面、圆柱、圆锥、球面、圆环，均存在属于下列 14 维空间的非零隐式多项式（它覆盖的形状多于这五类）：

`[1,x,y,z,x²,xy,xz,y²,yz,z²,x r²,y r²,z r²,r⁴]`，其中 `r²=x²+y²+z²`。

令见证特征矩阵为 A。带列主元且二次正交化的 QR 只提议一个左逆 B，不直接作为排除依据。区间运算独立验证 `rho >= ||I-BA||∞`、`M >= ||B||∞`。当 `rho < 1` 时，任何系数满足 `||c||∞=1` 的隐式多项式都具有 `||Ac||∞ >= (1-rho)/M`。这意味着每个解析母面都至少有一个源见证无法任意接近该母面。

在包含见证且向外扩展 1 的归一化立方盒内，若各坐标绝对值至多 b，则梯度 L1 范数上界可取 `L=3+12b+27b²+36b³`。由线段上的中值不等式，可得对所有五类母面成立的最大距离下界：

`d_lower = scale * min(1, (1-rho)/(M*L))`。

残差、范数、L 及最后的距离下界均用向外舍入求界；只在向下舍入后的 `d_lower > distanceTolerance` 时拒绝。这是由有限见证证明“不可能整体达标”，并非用有限采样证明“整体达标”。代码按 `/fp:strict` 编译，并检查舍入模式及 FTZ/DAZ。

当前快速证书限两方向次数不超过 5、控制点不超过 512、有效结点单元不超过 32；超限、病态、秩不足、非正分母、非有限区间、证书下界不足及不支持的浮点环境均返回未能证明。局部预算 8 ms 与全局截止时间同时检查；协作式限时不保证硬实时抢占。该方法是充分排除条件，不能发现所有负例，例如属于同一隐式多项式空间的椭圆柱可能保持秩亏，仍须交回原优化器。

## 计时、依赖与证据

只计时完整 `ConvertIsoThenFallback` 调用，包含等参识别、候选生成、已执行的验证及排除证书；STEP 导入、初始化、文件输出和报告生成均在计时外，不调用拓扑重建。排除器时间已包含在总时间内，不能再次累加。每例独立进程、同一导入曲面连续调用三次；10 秒进程看门狗用于防止测试进程挂死，与 API 自身 50 ms 限制分别记录。本轮没有将 API 放宽到测试规范一般允许的 150 ms，也没有重跑其余 900 例。

| 接口/检查项 | 本批实际情况 |
| --- | --- |
| `ConvertIsoThenFallback` | 完整调用计时 |
| 精确路径识别/验证 | 已包含，失败后进入兜底 |
| `rational_boundary::Validate` | 初值验证已包含；内部采样超差提前返回 |
| 连续边界位置/切向 | 原实现保留，本批在进入这些步骤前已拒绝；不记为已通过 |
| 五类母面整体排除 | 已包含，每次调用一次，实际区间距离证书 |
| 输出内部/边界距离及法向误差 | 没有输出面，均不适用 |

生产算法基于 SGK 的 BSplineSurface 存储、提取及原候选/验证设施，新增 QR 和区间证书为项目自有 C++ 实现，无新增 Eigen、BLAS、NumPy 等第三方依赖。算法链接 SGK Foundation、Math、GeomBase、Geometry、BSplineAlgo；外置适配器另用 Topology、ModelingBase、StepExchange、DataExchangeBase 做导入。Python 仅用标准库调度及汇总，不参与被测计算。

三轮结果、证书下界和状态稳定，无崩溃、非有限证书或卡死。未进行分配级内存泄漏检测，内存泄漏结论为“未能判断”。单测日志中的 SDK 日志文件打开提示不影响返回状态，正式 STEP 适配器关闭 SDK 日志输出。
