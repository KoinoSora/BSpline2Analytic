# 共享源数据与一维四边认证

基线：`14d6c3b0d9e348caa4faf15f7f1534345cc13a3d`。本轮实现已审核方案中的共享数据与一维四边认证，仍以独立 `ValidatePairedConversion` 为载体。分类内部增加可选恢复数据输出，候选生成、评分及排序规则保持原样；正式 `ConvertApproximate` 的验证器选择、优化器、共享区间运算及有理识别分支没有切换。

## 实现

1. `SourceCache` 保存固定平移坐标系下的只读源面分片和四边导数、法向。首次准备后移动所有权；缓存命中直接引用，不复制整份分片，也不按候选标架重新变换源系数。公开上下文仍逐项比较源控制点、节点、重数、次数和参数域，内容变化即重建。
2. 源面仅平移到控制点包围盒中心 `Os`，不旋转、不缩放。目标规范表示 `Nc/W` 按 `Ns = R Nc + (oc-Os) W` 变换，法向仅乘 `R`，保留权重因子及原方向约定。位置认证仍计算 `E = W(S-Os)-Ns`，保持严格区间运算及原容差。
3. `RecoverApproxPatch` 可输出边界轨迹；`RecoveredCandidate` 保存轨迹对应的母面参数及分类采样标记。内部 `AnalysisContext` 将分类采样、恢复结果与源面缓存连接起来；需要分段映射时才使用轨迹。跨上下文或母面参数改变时重新投影。内部上下文只在源面不变的一次转换中使用，公开可复用缓存不保存跨调用的源面裸引用或候选认证结果。
4. 四边认证从二维遍历中移出。源面首次准备时复用已提取分片的边界及相邻控制行，用一维差分生成沿边、横跨边界的偏导，再按 `Su × Sv` 构造法向。这样避免再执行一次边界提取矩阵乘法，也不构造完整二维导数。非夹持节点、重复节点、裁剪及 SDK 的一个浮点单位端点偏移保留相应单侧求值。
5. 目标四边只准备一次。切向使用 `N'W-NW'`，法向使用已有解析法向表达。先统一插入图册分界、冻结 U/V 映射，再分别执行二维位置和一维边界认证；边界认证不修改映射。每条边只合并沿边的源节点、最终映射节点和图册分界。
6. 每个一维根分段构造切向、法向的点乘与叉乘多项式，再用系数界认证角度；必要时细分这些一维多项式。四边与位置认证共享整次节点预算。只有全部连续域、四边及方向检查通过才接受；未完成覆盖不能输出完整上界。

第一版直接额外收缩源 B-spline 边界，造成无缓存验证约 3% 的退化。最终实现改为共享位置认证已经需要的提取结果，消除了重复提取；下列数字均来自这一最终实现。

## 同批性能比较

Windows x64、MSVC 19.42、SGK 1.7.11、Release，区间模块 `/fp:strict`。40 个普通非有理球面，每例使用相同的真实分类首候选，对旧版无缓存、新版无缓存、旧版缓存命中、新版缓存命中四种模式各测三次，并轮换顺序。

程序已预热；“无缓存”指每次都重新准备源数据，不代表操作系统或 CPU 冷启动。分类、来源证书、日志和结果断言不计入这组验证器计时，没有运行优化器。空缓存对象构造不在验证计时内，首次填充成本单独记录。未固定 CPU 核，也不保证独占机器。

| 平均耗时，ms/例 | 修改前无缓存 | 新版无缓存 | 修改前缓存命中 | 新版缓存命中 |
| --- | ---: | ---: | ---: | ---: |
| 整次验证，外部计时 | 7.007 | 6.537 | 4.435 | 3.239 |
| 准备阶段 | 3.060 | 3.443 | 0.471 | 0.157 |
| 位置认证 | 1.941 | 1.897 | 1.948 | 1.890 |
| 四边检查 | 1.938 | 1.129 | 1.948 | 1.124 |

无缓存整次验证耗时减少 **6.72%**，缓存命中整次验证耗时减少 **26.97%**。两版首次填充缓存的平均验证耗时分别为 **7.063 ms、6.463 ms**。缓存性能只表示后续复验，不能替代首次成本。

新版将源边界准备 **0.638 ms**、目标边界准备 **0.028 ms** 计入准备阶段。因此不能把四边检查的 `1.938 → 1.129 ms` 全部称为首次调用加速。将这两项准备加回，新版首次边界相关成本为 **1.795 ms**；整次验证的外部计时没有遗漏这些成本。

新版源面提取平均 **2.625 ms**，位置认证平均 **1.897 ms**，仍是首次调用的重要成本。三轮共 1875 个位置节点均由快速界通过，无位置细分。

以每例三轮均值统计，无缓存超过或等于 10 ms 的案例从 **10/40** 减至 **7/40**，新版最大均值 **16.151 ms**，单轮最大值 **16.334 ms**。新版缓存命中单轮最大值 **8.570 ms**，但这不包含分类且不代表首次转换达标。**本轮尚未达到全部案例端到端低于 10 ms 的目标。**

数据：[comparison.csv](paired-shared-boundary-2026-10-15/comparison.csv)、[比较汇总](paired-shared-boundary-2026-10-15/comparison.summary.json)、[性能审计](paired-shared-boundary-2026-10-15/performance-audit.json)。比较工具从基线提取五个私有文件，仅重命名符号和提供测试用缓存包装；基线数值实现保留。共享区间、采样、数值文件及被调用的几何辅助函数均有一致性检查。

## 正确性与覆盖

| 检查 | 最终结果 |
| --- | --- |
| PairedValidation | 78159 项断言通过 |
| ClassificationGate | 64 项检查通过 |
| Regression | 3847 项断言通过 |
| PairedSphere | 三轮均读取 50 例，40 个普通非有理球面通过；其余维持原分流 |
| PairedDataset500 | 完整读取 500 例，280 个普通非有理案例通过 |

新增检查覆盖恢复轨迹复用与失效、公开源缓存修改失效、直接一维边界数据与独立二维导数参照、非均匀/非夹持/重复节点、单侧端点、五类母面及八种参数方向、旋转和大坐标平移、角度阈值两侧、需要一维细分的连续认证及四边共享预算。已有位置、切向、法向超差等负例继续通过。

500 例最终状态与基线逐例相同：**280 Passed、206 Unsupported、9 ClassificationFailed、5 NoCandidate**。Unsupported 包含 200 个有理输入和 6 个非有理退化输入；没有把不支持的案例算作成功。280 个成功案例的位置、切向、法向最大上界分别为 **3.4873667840582056e-6、0.0036273856342237125°、0.004193008425086796°**，满足原容差。

覆盖测试现在用一个共享上下文连接分类、恢复和新验证器，并在计时之外与相同采样配置下、不输出恢复数据的分类调用逐例比较候选数量、顺序和几何参数。相对于旧独立测试的无共享采样调用，其采样入口有所不同，因此不能将跨批次分类时间直接相除。

本批 280 个成功案例的分类加首次新验证平均 **7.872 ms**、最大 **37.825 ms**，**73/280** 不低于 10 ms。该测试没有运行优化器，也没有切换正式转换入口。这些结果用于记录当前绝对成本，不是旧新端到端加速比。

280 个案例均只提取一次源面、准备一次源边界；全部在仿射映射下通过，所以无需边界轨迹复用。轨迹复用收益由需要分段映射的专项测试验证，不归因于这 280 个案例。

三轮结果及覆盖审计：[summary.json](paired-shared-boundary-2026-10-15/summary.json)、[dataset500.csv](paired-shared-boundary-2026-10-15/dataset500.csv)、[状态审计](paired-shared-boundary-2026-10-15/coverage-audit.json)。构建、单元及覆盖日志位于同目录。本轮未运行全部通用路径测试，也未处理历史 Cone、Approximate 测试的既有问题。

覆盖 CSV 的 `old_ms` 仍表示原投影验证器 `ValidateConversion`，不是上一版独立验证器。覆盖汇总中的 `speedup` 不能作为本轮优化收益；本轮收益只使用上面的四模式 `comparison.csv`。
