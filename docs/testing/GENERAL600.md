# 一般兜底模块固定数据集：600 + 60

本批只测试 `ConvertGeneral`。600 个主案例和 60 个专项案例，与历史 500 个输入共同保存在 `tests/data/dataset500/`，共 1160 个 `.b2a` 文件。历史 `case-000.b2a` 至 `case-499.b2a` 和 `manifest.csv` 不改写。

| 数据集 | 文件名 | 清单 |
| --- | --- | --- |
| 历史 500 例 | `case-NNN.b2a` | `manifest.csv` |
| 新增主集 600 例 | `general-000.b2a` 至 `general-599.b2a` | `manifest-general600.csv` |
| 新增专项 60 例 | `general-extra-000.b2a` 至 `general-extra-059.b2a` | `manifest-general-extra60.csv` |

## 配额与生成

主集 000–499 为有解案例，500–599 为几何无解案例。标签由独立入库证书确定，生成器从不调用转换器。后续算法失败的正例不会被替换。

| 母面 | 主集正例编号 | NURBS | 非有理 | 点退化边 |
| --- | --- | ---: | ---: | ---: |
| 平面 | 000–099 | 50 | 50 | 0 |
| 圆柱 | 100–199 | 50 | 50 | 0 |
| 球 | 200–299 | 50 | 50 | 20 |
| 圆锥 | 300–399 | 50 | 50 | 20 |
| 圆环 | 400–499 | 50 | 50 | 0 |

250 个新的解析面片配置各生成一对有理/非有理输入。偶数编号为有理，奇数编号为非有理；有理输入使用实际非恒定正权重，平面也不例外。五类每类安排 20 个等参矩形、60 个斜向线性 PCurve 四边形和 20 个专项配置。球、圆锥的专项配置具有极点或锥顶退化边；圆柱和圆环专项配置跨越周期接缝；平面改变形状比例和节点分布。对参数角点施加 U/V 反向和交换，退化边因而不固定在同一方向。

最终控制点数按完整控制网 `nu*nv` 计数，包括退化边重合控制点。50–79、80–109、110–139、140–169、170–200 五档各 100 例，每档每类每种表示 10 例；包含恰好 50 和 200 个控制点。

在展开的解析 UV 域选择四个角点，以双线性映射 `Phi(s,t)` 将 `[0,1]^2` 映射到四边形，目标为 `A(Phi(s,t))`。对直边案例用区间 Jacobian 检查映射方向一致。曲面内部保持二维，球极点或锥顶只允许出现在边界。

拟合使用 Chebyshev–Lobatto 节点上的张量 Bernstein 插值，平面三次、其余六次。非有理输入直接拟合坐标；有理输入拟合 `W*F`，其中 `W=(1+a*s)*(1+b*t)>0`，再将齐次系数除以对应权重得到控制点。固定四个角点，并将退化边的整排控制点设为相同的三维点。随后在预算内插入非均匀节点。

本批曲面 NURBS 采用有误差证书的有理逼近，不声称斜向解析参数线可以精确转成有限阶 NURBS；平面本身可精确表示。输入不是通过删除权重产生的。

负例包括五类相似形状各 12 例，加 40 例一般自由曲面，有理/非有理各半。使用三次、10×10 控制网，在名义母面控制布局上加入不同位置的平滑形变；部分案例保持边缘控制点，仅改变内部。一般自由曲面另加入平面内扭曲。每例必须取得四次多项式排除证书后才能入库。允许确定性地增加形变以取得证书，判断不涉及转换器；本批 100 例全部在首次构造取得证书。

## 正例独立证书

测试端重新实现解析母面的坐标公式和 UV 映射，未调用生产投影、分类或优化函数。使用向外舍入区间运算与有理 Bézier 提取，对每个节点矩形计算：

`E = X - W * Taylor(A(Phi))`

解析正弦、余弦采用九阶 Taylor 多项式，加上 `|delta|^10/10!` 的 Lagrange 余项。齐次差的 Bernstein 系数界除以正分母下界，给出源样条与目标面片的同参数距离上界。必要时细分，预算耗尽不通过。底层区间/Bernstein 基础运算与生产代码共用，但证书没有复用 `ValidateGeneral` 的几何判断。

500 个主正例全部要求上界 `<1e-6`。对应映射覆盖整个解析四边形及其四边，因此同一个上界约束双向面片和边界 Hausdorff 距离。对源边界点的最近母面投影，三角不等式进一步给出其到对应线性 PCurve 三维像的 `2*upper` 上界，仍远小于 `1e-5`。这是几何容差下的线性约束，不把弧度误差直接当成模型长度。

证书不宣称源参数到投影 UV 的逐点解析恒等，也不把有限采样宣称为全域单调性证明。退化边以三维距离和邻接角点身份处理，不能将相同三维位置的不同 UV 角点合并。

## 负例独立证书

五类母面都满足某个非零、总次数至多四次的隐式多项式（圆环为四次）。因此排除所有这样的多项式零点集，是排除五类母面的充分条件，且无需限制圆心、半径和轴线的搜索范围。

对每个源样条在固定 13×13 参数网格上取得 169 个经过区间求值的真实见证点。取三变量总次数 ≤4 的 35 个单项式，经过坐标尺度归一化及 QR 基预处理得到评价矩阵 V。QR 仅改善条件，不用于直接声明证书成立。

对区间 Gram 矩阵 `V^T V` 用 Gershgorin 下界求出严格正的最小奇异值下界 `sigma`。在每个见证点周围物理半径 `rho=2e-5` 的邻域，对预处理后多项式基的梯度进行区间计算，取得总体 Frobenius 上界 G，包含坐标尺度的导数因子。

仅当 `sigma - rho*G > 0` 才接受无解标签。如果存在五类母面之一，使全部见证点距离它不超过 rho，则能选取该母面上的点 q；评价矩阵 `V(q)` 必须有非零核向量。但扰动界保证 `V(q)` 满列秩，产生矛盾。有限见证点在这里足以构成排除证书，不是采样拟合失败的推断。

该条件保守，例如一般椭球本身满足二次隐式方程，无法用本证书将它排除，即使它不属于本项目五类。证书失败只表示尚未证明，不能自动标为有解或无解。重新读取文件后必须重新计算证书，不信任文件中保存的 rank margin。证书还检查五类已知正例不会被错误排除。

## 专项 60 例

| 编号 | 检查 | 数量 |
| --- | --- | ---: |
| 000–019 | 在解析 UV 中加入弯曲边界；指定已知母面必须报告 NonlinearPCurve | 20 |
| 020–029 | 接缝、极点、锥顶及参数方向 | 10 |
| 030–039 | 球优先、保留球失败后的圆环尝试 | 10 |
| 040–049 | 容差上下两侧的指定母面检查，含 Greville 采样遗漏 | 10 |
| 050–054 | 无效容差/采样预算必须返回 InvalidInput | 5 |
| 055–059 | 验证预算设为 1，禁止发布成功面片 | 5 |

专项文件可复用主集几何配置来测试不同选项，不计作额外独立几何配额。球优先组将相似评分参数显式扩大，以确定性地触发策略分支；600 个主案例始终使用默认设置。非线性 PCurve 的标签针对已知母面，若转换器找到另一张通过独立验收的面，则不把它误记为几何无解。

容差组前五例到指定平面的距离为 `8e-6`，其后四例为 `1.2e-5`；这些平移后的平面仍然有解，不能作为全局负例。049 使用七次/二次 Bernstein 内部起伏，四边位于平面上；所有实际 Greville 检查点低于容差，而另一个内部点超过容差，用来检验连续验收。专项入库允许对已知目标使用单独记录的 `2e-5` 对比阈值，此阈值不传入正式转换器。

额外程序检查覆盖采样上下文构造时无求值、位置缓存升级法向时复用位置，以及重复索引访问不重新采样。

## 运行和结果

从模块根目录执行：

```powershell
.\Build.ps1 -Configuration Release -GeneralOnly
```

该命令仅构建 `BSpline2AnalyticGeneralDatasetTests` 并运行 `General600`、`GeneralExtra60` 两项测试；没有调用 `Convert`、`Recognize` 或 `ConvertApproximate`。每个正式案例只向 `ConvertGeneral` 提供输入面和选项。来源标签、已知母面及证书不传入转换器。指定母面的专项/诊断调用独立进行，不影响黑盒转换。

结果 CSV 默认在 `build/general600-Release.csv` 和 `build/general-extra60-Release.csv`。加载、入库证书、输出独立核验不计入转换耗时。成功输出另以恢复母面和四角构造双线性对应，要求同参数连续上界 `<1e-5`，并检查共享角点、SDK PCurve 一次性及 SDK/规范参数的三维求值一致性。此输出核验是保守充分条件；它未证明通过时，单列为独立核验未通过，不直接断言实际几何错误。

```powershell
python tests/SummarizeGeneralDataset.py build/general600-Release.csv
python tests/SummarizeGeneralDataset.py --extras build/general-extra60-Release.csv
```

汇总要求编号完整、无重复、证书和配额一致。支持多个分段 CSV 及 `--merge`，但缺行不能冒充完成。每组的分类加优化最大值按同一案例求和后取最大，不将两个阶段各自的最大值相加。

可在已设置 SDK DLL 的环境下、SDK 工作目录中直接运行测试程序：

```text
--generate <data-dir> [first last]       # 0..659，半开区间；不覆盖历史 case-* 文件
--certify <data-dir> <csv> [first last]  # 仅重新证明主数据标签
--run <data-dir> <csv> [first last]      # 主集默认 0..599
--extras <data-dir> <csv> [first last]   # 专项默认 0..59
--diagnose <data-dir> <id>              # 比较已知母面验收与独立候选尝试
```

当前真实结果见 [2026-10-13 测试报告](GENERAL600_REPORT_2026-10-13.md)。测试失败会保留非零退出码，不放宽生产容差或修改期望以获得绿色结果。

## B2A_GENERAL_V1 格式

文件为 17 位有效数字文本：标记行；`id group type bucket variant seed rational extra collapsedMask`；母面原点/轴/X 方向；SDK 曲面类型及半径/大半径/半锥角；四个规范 UV 角点；`bend storedUpper exclusionRadius storedRankMargin pairTolerance`；一张最终输入样条的次数、控制网尺寸、是否有权重；节点及重数；控制点及可选权重。

`type` 顺序为平面、圆柱、球、圆锥、圆环，5 表示一般自由曲面，和旧 Dataset500 的类型编号约定不同。四角顺序为 00、10、01、11；退化边掩码依次为 Umin、Umax、Vmin、Vmax。group 数值顺序在 `GeneralDataset.h` 中定义。输入几何是唯一正式转换对象，其他字段只服务于测试和证书。
