## 构造合同

五类母面分别构造测试侧的正权重有理 NURBS 图 `Q`。角向使用不超过 π/2 的有理二次圆弧，角度仅用于定义这个图的覆盖范围 `chartDomain`；不把解析角度当作 NURBS 参数。

在归一化 NURBS 图域内给出四个角点，构造双线性映射

`Phi(s,t) = (1-s)(1-t) q00 + s(1-t) q10 + (1-s)t q01 + st q11`。

参考面为 `R(s,t) = Q(Phi(s,t))`。四个参数侧的 `Phi` 都是直线段；允许一个侧退化成点，并认证映射在内部不折叠。保留母面位置、方向、半径、类别、种子、表示类型及退化边角色，不能把旧角度坐标直接写入新 PCurve 字段。

- 有理输入：分段组合齐次分子/权重，在 3–5 次内升阶及插结点；非线性专项中组合次数超出五次时，对齐次多项式做低次逼近，再由连续来源证书验收。
- 非有理输入：在局部坐标内拟合张量 B 样条。普通方向采用三次，角向变化方向采用五次；原圆弧分段结点保留 C1 连接，加密结点使用单重结点。以加密的余弦节点和 Greville 点作超定最小二乘拟合，固定两端值；根据误差变化选择插结点位置。采样只用于构造，最终接受依赖连续证书。
- 三角形、球极点和锥顶：恢复严格重合的控制点边，认证其余边的切向。
- 大坐标输入：局部构造后平移到世界坐标，并认证实际保存后的控制点；绝对坐标不超过 `1e6`。
- 100 个不可行负例：保留参考边界，扰动内部控制点，单独认证四边到直线 NURBS 参考边界的位置和切向，再证明给定距离容差内不存在任意非零四次及以下隐式多项式曲面，因此排除五类母面。负例标签不依赖兜底算法失败。

补充集 0–19 刻意增加 NURBS 域弯曲项，作为**非线性边界探针**，不混入直线边界正例，也不宣称所有替代参数图均不可行。20–39 保留周期/奇点与球面优先级场景；40–48 保留已知平面的容差内外偏移；49 将原有七次的内部扰动源面逼近为五次/三次表示，保留内部扰动探针用途，其参考域仍为单位平面 NURBS 域。新的 Greville 分布已经改变，不能沿用旧版“采样盲点”结论，后续获准测试时需重新测量；50–59 保留无效选项与预算专项。

## 来源认证及结果

来源工具不调用 `BuildChart`、PCurve 恢复、`ValidateGeneralRationalBoundaries`、`ValidateGeneralHybrid` 或 `ConvertGeneral`。参考构造与认证共享测试侧数学定义，并复用基础区间运算和 Bézier 提取。这里的区间运算属于**离线数据质量检查**，不属于兜底算法计时。

认证从实际写入并重新读取的控制点出发，包含重心平移的舍入包络。对齐源面和参考图的参数区域后，以

`G = Ps Wq - Pq Ws`，`H = Ws Wq`

认证 `|G/H|` 的连续位置界；用误差导数和源曲线速度下界认证四边切向。曲面法向不参与。算法几何验收阈值始终为 `1e-5`；数据构造优先采用更严格的 `1e-6` 来源容差，在次数/顶点预算用尽时普通案例最多允许到 `1e-5`。短弧仍取 `min(1e-6, 0.1 × 原场景弓高)`，更小的短弧容差不放宽；边界切向严格小于 `0.01°`。容差外偏移及内部扰动专项使用 `2e-5` 的来源描述界以容纳刻意设置的超差，**不修改算法的 `1e-5` 验收阈值**，也不将它们混入容差内正例。

跨圆弧分段时，把参考公式的有效区间拉回源域，以向外舍入保证交界处有覆盖而无空隙。先构造误差及导数，再限制到覆盖范围，避免把相邻分段外推到整块源面，也避免极窄交界区造成虚假的低速度。

| 子集 | 来源认证 | 位置上界最大值 | 四边切向上界最大值 |
| --- | --- | ---: | ---: |
| main | 600/600；含 100 个不可行＋边界证书 | `1.608e-7`（500 正例）；负例仅认证四边 | 正例 `0.0001333°`；负例 `0.003128°` |
| extra | 60/60 | `1.588e-5`（包含刻意超出算法距离容差的专项） | `0.0004025°` |
| extreme | 320/320 | `9.775e-6` | `0.009992°` |
| synthetic | 5/5 | `2.205e-13` | `2.810e-8°` |

另以每面 17×17 个 SDK 评价点交叉检查配对距离与连续证书的一致性；采样不替代连续证明。几何尺寸采用每边 128 段折线。不可行负例不计算到指定参考母面的配对误差，其 `source_bound=-1` 表示不适用，全局不可行依据为正的排除秩裕量，同时 `boundary_source_bound` 和切向列另行保证四边满足参考约束。

## 运行入口和历史数据

`GeneralRationalDatasetTests` 只提供 `--generate` / `--audit`。生成器先写 `.pending`，重新读取并认证通过后才发布 `.b2a`；不会覆盖已有输入。`GenerateGeneralRationalDataset.py --resume --audit` 可完成剩余生成并复核全部文件。完整命令见 [tests/README.md](../../tests/README.md)。

当前兜底测试入口和恢复诊断已改为 V2 加载、版本及来源认证检查。全量运行器从新清单读取期望，固定图诊断与实际分类入口明确分开；运行器传递旧程序不接受的 `--rational-v2-only` 标记；运行器及汇总检查合同、输入哈希和基线，不沿用旧 240 例失败清单。旧案例 254 的预期失败断言已删除，新同编号仍是正例，实际能否认证尚未测试。

`dataset500/general-*.b2a`、`general-extra-*.b2a`、`general-extreme320/` 原文件未修改，仅增加废弃说明；旧入口/CTest 已禁用。`case-*.b2a` 专用路径保持原用途。旧报告留作历史证据，不得按旧命令重跑。
