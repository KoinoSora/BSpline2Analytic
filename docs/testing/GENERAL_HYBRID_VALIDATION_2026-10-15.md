# 独立混合验证器与一般兜底数据测试

> 已归档：2026-10-15 起 `ValidateGeneralHybrid` 废弃，保留代码但不再运行本报告的测试或性能对照。当前验证器及命令见[测试说明](../../tests/README.md)。

日期：2026-10-15。基于 `1b9ee3e6437f8b1791cb3c4de04752a961fb2e0d`。Windows x64、MSVC 19.42、SGK 1.7.11、Release；新验证实现及区间运算使用 `/fp:strict`。未固定 CPU，也未保证机器独占。

## 实现范围与验收合同

新增公开接口 `include/GeneralHybridValidation.h::ValidateGeneralHybrid`，实现位于 `src/GeneralHybridValidation.cpp`。原 `ConvertGeneral`、统一入口、分类器、优化器及原连续验证流程均未替换。

- **内部为采样证据。** 复用 `SurfaceSampleContext` 的增强 Greville 网格；它已包含有效节点区间中心和少量补充点，并非只有纯 Greville 点。检查完整网格，不只检查用于候选评分的子集。距离对应当前候选重新计算。报告记录样点数量、母面距离最大值和有限面片距离见证最大值，`certifiesInteriorContinuum` 恒为 `false`。
- **有限域检查。** 投影在域外或内部剖分对角线的浮点符号判断不确定时，在裁剪域三角形内构造实际目标点并测量距离。该距离是样点到有限域的上界见证，不能声称求得精确最近点。没有用扩大几何容差的办法放行域外点。
- **边界为连续证据。** 通过一维、向外舍入的齐次 blossom 运算直接提取四条源参数边界，支持正权重有理输入和非有理输入。不会为此构造整张面二维 Bézier 控制网。非有理分母保留为常数 1，避免不必要的乘积次数增长。
- **一般 PCurve。** 复用现有边界恢复、周期展开和坐标系恢复；目标采用解析母面与直线 PCurve 的复合。三角函数用十项 Taylor 多项式加严格余项包围。没有把 SDK `SPCurve::ApproxCurve()` 当成精确曲线，没有产生未经认证的目标拟合误差。
- **一维对应。** 首先尝试简单参数对应；在必要的源分片和递归子区间中，用投影样点提出新的映射端点。端点必须严格递增、连续连接，并完整覆盖目标 PCurve 的 `[0,1]`。采样只用于提议映射，接受由区间误差界决定。
- **位置与切向分别认证。** 复用新配对验证器的 Bernstein 乘法、升阶、快速界与紧界。位置界包含三角函数余项；切向通过独立包围的解析导数与源曲线有理导数分子计算点积/叉积界，不对位置近似的余项直接求导。默认位置严格小于 `1e-5`、切向夹角严格小于 `0.1°`。精确退化为点的源边界，其切向通过 `tangentNotApplicable` 标明不适用；不能称为零切向误差。
- **预算与失败。** 默认边界节点预算 2048、递归深度 12；节点预算累计当前候选的多个坐标系尝试。无法认证时返回无输出面片的结果，不自动调用原连续验证器或优化器。节点预算不是整个调用的硬实时截止时间；坐标系恢复仍可产生长尾。

这份合同不认证内部全域最大距离，也不认证边界处曲面法向。`Passed()` 表示上述采样/连续混合合同通过，不等同于原 `GeneralValidationReport::Passed()` 的连续曲面合同。

独立单测覆盖五类母面、有理与非有理输入、参数反向、直接边界提取与 SDK 点值交叉检查、错误母面、非法容差、边界节点预算、切向超差、非线性单调边界参数对应、有限域外的内部样点，以及平面内部剖分对角线导致的误拒绝回归。

还显式保留一个**采样盲区检查**：构造四边完全平直、增强 Greville 样点全部合格、实际内部峰值略大于 `1e-5` 的面片。独立接口按采样合同接受该面片，且不能声称内部连续认证。这一案例不混入固定数据集的正负例配额；它用于证明接口局限确实存在，而非将采样结果伪装成全域上界。

## 批量测量口径

使用原有 600 个主案例（500 正例、100 具有无解证书的负例）及 60 个专项，输入文件不重新生成。每例串行测量三次，运行器为每例进程设置 30 秒看门狗。所有样本都由原分类器生成真实候选，并按既有候选批次逐个交给新验证器；生产路径不读取来源母面、来源角点或正确答案。

源数据证书、独立输出证书、数据加载、日志和进程启动不进入算法计时。`validate_ms` 累计当前案例全部候选的独立验证耗时，包含内部样点检查、PCurve/坐标系恢复、边界准备及连续认证；`pipeline_ms` 是从分类开始至新验证流程返回的墙钟时间，包含共享样点首次准备和失败候选尝试。**不运行母面优化，不是完整 `ConvertGeneral` 或统一入口的计时。** 候选参数发生变化后的验证结果不会复用。

源面点缓存来自本次分类，边界分片在每次候选验证中首次准备，并在其坐标系尝试间复用；本轮没有将跨候选边界缓存命中计为首次准备。CSV 工作量计数累计所有候选，`samples` 与误差值属于最终尝试。精度值与输出独立审计逐次保存。

分位数使用每个案例三次流程耗时的中位数、最近秩定义；另列三次均成功且三次均不超过 10 ms 的案例数。失败和超时不能通过移出分母来提高达标率。进程看门狗也覆盖证书和审计阶段，不能把任意进程超时都叫作算法转换超时。

## 最终数据结果

660 例均完成三次运行，共 1980 行。进程退出码 0，无看门狗超时、进程失败、独立输出审计失败或三次结果状态不一致。运行器墙钟时间为 558.781 秒，包含证书、审计、加载与逐例进程启动。

## 复现

在仓库根目录执行：

```powershell
cmake -S . -B build-general-hybrid -A x64
cmake --build build-general-hybrid --config Release --target BSpline2AnalyticGeneralHybridTests BSpline2AnalyticPairedValidationTests BSpline2AnalyticTests --parallel 2
ctest --test-dir build-general-hybrid -C Release -R '^BSpline2Analytic.(GeneralHybridUnit|PairedValidation|Regression)$' --output-on-failure
python tests/RunGeneralHybrid.py --exe build-general-hybrid/Release/BSpline2AnalyticGeneralHybridTests.exe --sdk ../../../SGGK --data tests/data/dataset500 --output build-general-hybrid/final660.csv --runs 3 --timeout 30
```

本轮不包含 GeneralExtreme320、原等参 Dataset500 全量转换、旧 Approximate/Cone 等测试，也不包含原兜底转换流程的全量重跑。性能结论限于上述固定数据及当前独立验证流程；与历史连续验证报告的合同不同，不据此给出同等保证下的加速倍数。
