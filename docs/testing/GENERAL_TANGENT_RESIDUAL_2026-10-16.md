# 一般兜底切向残差替换（2026-10-16）

本轮按“主分支1.2（等参专用分支优化）”的正比例缩放残差思路，替换当前一般兜底验证器的切向叉乘后备。**仅编译和静态检查，未运行任何测试程序、数据集、性能测试或包络数值审计**。没有新的通过率、无退化或耗时达标结论。

## 修改范围

- `GeneralBoundaryError.cpp`：选择严格为正的常数、一次或二次辅助多项式；构造区间残差；计算连续正弦平方上界。
- `GeneralBoundaryEnvelope.cpp`：通过双精度 Bernstein 系数和舍入误差半径构造相同残差，常数缩放直接遍历系数；中点超限见证改为点积与平方长度。
- `GeneralRationalBoundaryValidation.cpp`：保留原误差导数快速检查，替换双精度包络及区间后备中的夹角核；每次改变参数对应后重建残差。
- 报告结构、全量/选例 CSV 与汇总脚本：增加残差尝试、通过及区间后备计数。区间后备计数包含未启用包络时的直接区间调用；每个区间后备计数也属于尝试计数，不能相加当作总次数。

不修改等参专用分支、旧验证器或固定数据。分类、球面坐标系候选构造中的普通向量叉乘保留。测试侧独立 SDK 输出审计也保留点值向量叉乘，以便将来用不同公式交叉核验；它不构造样条叉乘、不参与算法验收和计时，本轮未运行。

## 连续证书

在源曲线与目标曲线的共同局部参数下，使用有理导数分子 `A=P'W-PW'` 和对应的 `B`；正权重分母不影响方向。根据端点及中点的双精度估计选择 `lambda`，实际保存的浮点系数定义辅助多项式本身。采样仅用于选择，连续正性和完整残差必须另外认证。

构造 `R=A-lambda*B`。残差各分量统一次数时，用 Bernstein 向量控制系数范数的最大值包住 `||R||`；次数不同时使用分量范围盒。选固定非零参考方向 `e`，以 `min(A·e)>0` 和 `||e||²` 构造源切向长度平方下界 `m²`。所有界均带向外舍入保护。

当 `lambda>0` 且 `q=E²/m²<1` 时，两个切向非零且同向，整个区间满足 `sin²(angle(A,B))<=q`。通过条件为 `q < lower(sin²(tangentTolerance))`。原快速路径仍比较正切界；两类界分别累计，最后统一转换为报告中的角度上界，不在节点递归中求反三角函数。

默认几何容差仍为 `1e-5`，沿边切向容差仍为 `0.1°`，原可配置容差继续生效。未引入曲面法向或 U/V 联合角度检查。

## 后备与细分

1. 位置界通过后，先执行原误差导数快速检查。
2. 快速检查不通过时，尝试带误差包络的正比例残差。
3. 包络不能证明时，以区间系数重新计算残差；若已有辅助缩放函数则复用该函数，避免重复选择。
4. 仍无法认证时，使用原节点/深度预算细分。目标参数区间可能经 `Fraction` 重新调整，因此子节点重新选择缩放函数，不能直接细分旧残差后复用。

中点超限见证使用 `1-(A·B)²/(||A||²||B||²)` 的区间下界，与角度阈值的上界比较；先检查非零切向和方向。该恒等式在小角度下可能因消去而无法证明，届时继续正常求界。见证只用于当前参数对应，不直接证明所有对应均不可行。残差界过大、参考投影下界不足或辅助比例选择失败，均只表示未认证。

## 编译与静态检查

Release 编译目标：`BSpline2AnalyticGeneralRationalBoundaryTests`、`BSpline2AnalyticGeneralRationalRecoveryDiagnostics`。使用 `/fp:strict` 的原编译设置。Python 修改仅作 AST 语法检查，CSV 表头/输出字段数作静态核对。

已更新但未执行的检查代码包括：同向不同速度、变动正比例、反向、零切向、采样之间的角度缺陷、阈值两侧的点值见证，以及独立 Fraction 残差系数包络/连续角度界审计。旧验证器与旧数据的禁测约束保持有效。

新核将每次后备中的完整点积/叉乘乘积改为三条低次缩放乘积；有理切向分子构造、位置检查和参数恢复仍有成本。若低次比例近似较差，细分次数可能增加，实际耗时与认证率须待后续授权测试后判断。
