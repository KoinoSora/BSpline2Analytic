# 极端场景测试报告（2026-10-13）

本轮新增并测试 **200 个极端面片与 7 个模块诊断**。200 个输入全部通过重拟合距离连续界和控制点预算检查。转换结果为：**68 个同类型成功，34 个其他类型成功，89 个验证失败，8 个 InvalidInput，1 个超时**；成功结果均通过附加的距离及角度数值复核。模块诊断 **7/7 通过**。本轮没有修改算法，也没有复测旧数据集。

这不能表述为“102 个案例已证明全部约束”：其中 **40 个**具有非有理专用分支的连续角度报告，另外 **62 个**通过的是角度加密采样复核；通用入口的有理分支和一般回退当前只提供几何/边界距离的连续验证。失败也不表示不存在可行解析面。

## 1. 环境与数据资格

- 算法基线：`288e500ebc44632da7d786ffc95a210e60d2b3eb`，Release x64，Visual Studio 2022，SGK 1.7.11。测试期间算法源码及静态库未变动。
- 默认几何容差 10⁻⁵，边界切向及法向角各 0.1°；算法内部预算和参数均未调整。
- 输入来自五类解析面的等参裁剪和 SDK 解析转换。100 个配置各有解析转换与非有理重拟合两份输入，实际控制网全部为 64 点，符合 [50,200]。
- 200 例的同参数连续距离上界最大为 **7.61616411e-07 < 10⁻⁶**。四边数值弧长均在 [0.005,50000]；弧长采用逐节点区间积分，未把它称为严格区间证书。
- 有源面数值复核记录的 199 例中，输入到已知母面的采样距离最大为 **5.52383582e-07**；相对来源 NURBS 的边界切向、法向角最大为 **0.004448°、0.007454°**。超时案例未写出这三个统计值。
- 200 个面片和清单重新生成后，**201 个文件的 SHA-256 全部一致**。来源、权重、实际有理性、ULP、边长和证书值均保存在 [固定清单](../../tests/data/extreme200/manifest.csv)。

构造矩阵、复核对应和复现入口见 [EXTREME200.md](EXTREME200.md)。角度复核沿输出边界寻找近点，不将样条参数直接当成解析角参数。

## 4. 关键问题及模块诊断

**固定角跨度门槛截断回退。** 97、99、105、107、113、115、121、123 均为通过输入资格的非有理面片。它们的 θ 为 0.8×10⁻³ 或 0.99×10⁻³ rad，指定圆边界半径为 10⁴；前者弓高约 8×10⁻⁴，已经是几何容差的 80 倍。`IsoCurveAnalysis.cpp` 中圆拟合要求跨度大于 10⁻³；直线又不能满足候选误差，因而抛出 `InconsistentBoundary`。`ApproximateConversion.cpp` 将该状态映射为 `InvalidInput`，`SurfaceConversion.cpp` 随后提前返回，通用回退被跳过。这是可明确定位的分类/状态处理问题。

**证明代价远大于求初值。** 82、83、89 等小弧圆环案例，以及接近极点/锥顶的 8 例，最终没有得到通过验证的输出；总耗时中验证占主导。记录中的“连续界未解决”“周期分支/边界环失败”应区别于已经找到几何超差见证。

**极端圆环比例超时。** 147 为 R/r=10⁶ 的非有理圆环。初次执行超过五分钟后被外部停止；隔离复测在 **300.092 s** 看护上限处终止。日志有 `BEGIN_CONVERT 147` 而无 `END_CONVERT`，表明超时发生在转换内部，尚不能据此精确分摊到三个阶段。它不是几何无解证据；对应的有理案例 146 也未转换成功。

**角度验收与 Jacobian 诊断。** 从本批 197、159、105、165、171 分别建立平面、圆柱、圆锥、球、圆环的偏置初值。尺寸/偏移一级优化均执行 1 次，最大归一化采样误差从约 2–2.67 降到小于 0.009；本次被检列的解析 Jacobian 相对中心差分误差不超过 4.08×10⁻¹⁰，未触发差分回退。另两个 0.0051×0.0051 小平面诊断分别加入 0.15° 边界方向或法向偏差，均在位置验收通过的同时正确拒绝角度超差。这些结果只覆盖所测尺寸/偏移列和样本，不构成全参数求解器收敛保证。

后续优先顺序：先修正识别失败与非法输入的状态映射；再依据几何容差、弓高和数值条件调整圆弧可辨识判断；随后剖析连续验证的候选次数与细分开销，并补齐通用入口的连续角度验收。本轮保留算法原状作为后续比较基线。
