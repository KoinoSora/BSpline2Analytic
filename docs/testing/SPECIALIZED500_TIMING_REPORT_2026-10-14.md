# 等参专用路径 500 例四项计时复测（2026-10-14）

本轮将初始候选验证计入分类、求解后验证计入优化，同时保留四项明细。算法基线为 `f636845e1fa65c207759efac0982dd007bed5d3d`；生产代码仅调整计时字段、计时归属和统一入口汇总，没有修改候选生成、优化步骤、容差或验证预算。

**固定 500 例全部重新加载并通过输入资格检查：460 个普通案例全部转换成功；40 个退化案例中 25 个返回预期的 Degenerate，15 个返回其他失败状态。因此本轮不是 500/500 回归通过，Dataset500 的 CTest 退出码为 8。**

## 测试入口与计时定义

按照实际输入表示，200 个有理输入直接调用 `Recognize`，300 个非有理输入直接调用 `ConvertApproximate`。不调用统一入口，不执行一般兜底或统一入口额外 PCurve 验证。250/250 是来源配额；50 个精确来源平面实际属于非有理输入。原有数据文件未修改或重新生成。

| CSV 字段 | 含义 |
| --- | --- |
| classify_compute_ms | 分类计算；精确路径包含边界分析、候选重建、参数域恢复，非有理路径包含完整 ClassifyApproximate |
| classify_validate_ms | 每个初始候选的验证，包含失败的候选尝试 |
| optimize_compute_ms | 优化采样准备、补点、求解与输出对象更新；异常前已发生的准备时间也保留 |
| optimize_validate_ms | 每次求解之后的验证，包括零迭代尝试及失败后的验证 |
| classify_ms | classify_compute_ms + classify_validate_ms |
| optimize_ms | optimize_compute_ms + optimize_validate_ms |
| classify_optimize_ms | 本轮评价耗时：以上四项相加 |
| other_ms / total_ms | 未归属四项的调度等时间 / 完整专用接口调用时间 |

计时标记为 `specialized-v2`。四项明细是阶段总计的组成部分，不能再加到阶段总计上。独立专用接口的 `validate_ms` 为零，不表示没有验证。旧报告的 classification/optimization 不包含各自验证，不能直接比较同名字段。所有候选和反馈轮次累计；calls 是计时区块次数，不是迭代次数。`jacobian_ms` 属于优化计算内部，不重复加入总计。有理边界识别内部的直线/圆界检查仍属于边界分析；`classify_validate_ms` 对应构造后曲面候选的 ValidateCandidate 调用。

Windows x64、MSVC 19.42.34435.0、SGK 1.7.11、Release；独立目录 `build-specialized-timing`，串行运行。每类型/实际接口首次非退化案例先预热一次，每例正式测量一次。SDK 初始化、文件读取、来源重建、输入证书、预热和日志不计入转换耗时。没有独占机器或绑定 CPU，P95 是跨案例的 nearest-rank，不是重复测量的置信区间。
