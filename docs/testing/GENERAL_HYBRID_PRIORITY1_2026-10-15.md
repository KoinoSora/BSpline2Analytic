# 独立验证器第一优先级优化：小样本对比

日期：2026-10-15。基线算法提交：`246e40173721e6cbbeaaf9dc7614bf35f5e023e2`。
Windows x64、MSVC Release、区间算法 `/fp:strict`、SGK 1.7.11。

## 修改范围

实现位于 `src/GeneralHybridValidation.cpp`，公开接口不变。

1. 切向容差的正切下界在每次需要边界认证的候选验证中计算一次，在坐标系尝试间共享。最终实现将这次准备计入 `boundary_ms`，也包含在验证和流程总耗时中。
2. 分片只累计最大切向正切比值。四条边全部认证通过后，计算一次区间反正切，得到报告中的角度上界。失败尝试不转换角度，点退化边界仍显式标记切向不适用。
3. 每个恢复后的 `GeneralTrim` 拥有独立目标上下文，缓存坐标架、半径、圆锥半角正切及四条 PCurve 的起点/方向增量，不跨坐标系尝试复用目标常量。
4. 同一角度的正余弦联合构造，共享展开中心、区间中心正余弦、幂次、阶乘和余项。球面使用三个角度对，圆环使用四个角度对；圆锥同时复用高度与正余弦的乘积。

仍使用九次 Taylor 多项式加十阶余项。解析切向独立包围，不对位置余项求导。严格位置/切向判据、边界提取、映射细分、内部采样合同和正式转换入口均未改变。

## 验证范围

遵照本轮要求只测试代表案例，没有运行 660 例全量测试。

- `GeneralHybridUnit` 通过，1955 项断言；覆盖参数反向、错误母面、非法容差、预算、切向超差、非线性参数对应、内部采样及有限域等。
- 固定选取 12 例：主案例 `0,100,101,218,254,318,400,401,500`，专项 `0,50,55`。
- 其中 8 个正例覆盖五类母面、有理/非有理输入、球面和圆锥点退化边界、球面多坐标系恢复长尾；另有无解负例、非线性 PCurve、非法选项和预算专项各 1 例。
- 比较原版 `baseline`、常量缓存/反正切延后版 `cached`、完整优化版 `optimized`。每版每例串行运行 5 次，最终比较共 180 行；此前用相同案例做过一轮预检。
- 三版均为 8 例接受、4 例拒绝/未认证，全部输入证书和已接受输出的独立审计通过。逐次对比接受状态、输出类型、候选数、节点数、细分数、退化边界数、坐标系计数等，差异为 0；内部距离、有限域样点距离、边界位置上界和切向角度上界的 CSV 值差异也为 0。

源证书、输出审计、文件加载和进程启动在算法计时之外。`pipeline_ms` 为分类加独立验证，不含母面优化，也不是正式完整转换流程。未固定 CPU，机器不保证独占；案例间轮换版本运行顺序。本次未重跑其他模块的全量回归。

## 最终性能结果

以下先对每例 5 次取中位数，再对 8 个正例求均值。不要把该小样本均值与上一轮 500 例均值直接比较。

| 阶段 ms | 原版 | 缓存中间版 | 完整优化版 | 原版至完整优化版降幅 |
| --- | ---: | ---: | ---: | ---: |
| 边界准备 | 1.111 | 1.118 | 1.106 | 未针对性优化 |
| 边界连续认证 | 3.914 | 3.345 | 2.841 | 27.4% |
| 独立验证总计 | 8.593 | 7.961 | 7.621 | 11.3% |
| 分类加验证 | 9.115 | 8.521 | 8.177 | 10.3% |

中间版的单次阈值准备已包含在验证和流程总计中，但尚未归入 `boundary_ms`；完整优化版已补齐该阶段归属。因此中间版仅用于辅助观察，最终降幅以原版和完整优化版比较。

| 案例 | 类型 | 边界认证：原版 → 优化 ms | 分类加验证：原版 → 优化 ms |
| --- | --- | ---: | ---: |
| 0 | 平面，有理 | 1.316 → 0.379 | 2.100 → 1.330 |
| 100 | 圆柱，有理 | 3.049 → 2.448 | 4.762 → 4.132 |
| 101 | 圆柱，非有理 | 2.090 → 1.481 | 3.679 → 3.112 |
| 218 | 球面，点退化边界 | 3.811 → 2.911 | 5.715 → 4.879 |
| 254 | 球面，恢复长尾 | 9.574 → 7.062 | 39.937 → 38.252 |
| 318 | 圆锥，点退化边界 | 3.179 → 2.512 | 4.996 → 4.341 |
| 400 | 圆环，有理 | 4.642 → 3.414 | 6.436 → 5.188 |
| 401 | 圆环，非有理 | 3.650 → 2.520 | 5.295 → 4.185 |

8 个正例中，流程中位数不超过 10 ms 的数量仍为 7/8。案例 254 的恢复长尾没有被本轮优化解决。不能据此声称全量数据已达到绝大多数低于 10 ms。
