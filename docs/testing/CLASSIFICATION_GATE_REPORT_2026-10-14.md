# 分类状态与短圆弧门槛修复报告

本轮修复专用分类分支的失败状态映射，以及圆拟合的固定角跨度、方差比例两处筛选。仅运行 96—127 号角跨度组和定向回归；未运行完整 Extreme200、Dataset500 或 General600。

## 1. 修改与判定语义

- `InconsistentBoundary` 映射为 `NoCandidate`；`IllConditioned`、`Ambiguous` 与异常形式的 `VerificationFailed` 映射为 `Unresolved`。真实输入/选项错误仍为 `InvalidInput`。正常验证报告发现的超差仍为 `VerificationFailed`。
- 取消 `abs(sweep)>1e-3`。圆候选要求数值秩足够、参数有限、半径为正、弧长数值上非零，以及采样圆距离不超过候选容差。当前候选容差为 `20*1e-5=2e-4`，最终验收容差保持 `1e-5`。
- 方差比例 `lambda1/lambda2<1e-10` 改为诊断信息。只有直线候选成立且横向偏离不超过数值分辨率估计时才跳过圆拟合；否则继续由带列主元 QR 检查数值秩。数值估计为 `8*max_coordinate_ULP + 64*machine_epsilon*local_scale`，属于启发式筛选，不能作为连续几何证书。
- 用相对于首点的偏移累加加权中心，减少世界坐标求和误差。保留同时成立的直线、圆候选。
- `ClassificationDiagnostics.isoCurveFits` 保存逐等参线的误差、半径、跨度、弓高、数值尺度及拒绝原因。`ConversionAttempt.isoCurveFits` 在进入通用回退后继续保留这些记录；逐例运行器输出额外的 `*-fits.csv`。

新增 `BSpline2Analytic.ClassificationGate` 回归 **64 项检查全部通过**，用时约 0.40 秒。覆盖短弧、旧方差比例门槛、精确/数值直线、双候选、非圆曲线拒绝、非有限点、实际分类失败回退、采样预算耗尽回退、非法选项拦截及原 8 例边界拟合。半径 `1e8`、跨度 `1e-5` 的定向曲线方差比例约 `1.864e-12`，成功跨过旧筛选；另以独立加密点核验其曲线误差。

8 个成功输出的采样复核最大距离为 `8.004e-11`，最大切向角为 `6.671e-9°`，最大法向角为 `9.789e-9°`。其中 3 例有专用分支连续角度报告，另外 5 例只有角度采样证据；本次未补充通用分支的连续角度验证。原始运行器因剩余 24 例未成功而返回 1，该返回值如实保留。

```powershell

ctest --test-dir build/gate-fix -C Release -R '^BSpline2Analytic\.ClassificationGate$' --output-on-failure
```
