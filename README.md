# BSpline2Analytic

基于海星 SGK 1.7.11 的 NURBS 曲面片解析识别与转换项目。

## 当前状态

项目处于需求与算法方案阶段，尚未实现 C++ 算法、构建目标或测试程序。本次初始提交保存需求 PDF、已确认的需求和代码实施方案，后续在此仓库中实现模块。

## 当前范围

输入为由平面、圆柱面、圆锥面、球面或圆环面精确转换得到的四边 NURBS 面片，四条边界对应原解析面的两对参数等参线。允许节点插入、升阶以及其他保持几何不变的表示操作。

首先实现四条边界的直线／圆弧识别，再利用边界之间的几何关系恢复解析母面、面片参数范围，并验证转换结果。
